# Tasks

Index of open tasks. Each active task gets a file in
`.agents/tasks/<name>.md`; only the line pointing to it remains here, along with
the responsible agent and status.

A completed task is removed from here and its file is discarded. Anything from
it that is worth preserving becomes a memory in `.agents/memories/` and is added
to the `.agents/MEMORY.md` index — execution state does not age well in memory.
