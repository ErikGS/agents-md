# Workflow

This memory should be kept up to date with the operator's and repository preferences, and should be read and followed by all agents.

Whatever the operator conversational language:

- Code comments and inline documentation must be in {repository-spoken-language}
- Commit messages and other git history must be in {repository-spoken-language}
- Repository documentation and other repository written content must be in {repository-spoken-language}
- Default application spoken language for user-facing content, must be in {repository-spoken-language}.

## Cycle

- The operator prefers well-justified decisions: when there is a choice, the
  agent recommends one and explains why instead of listing options.
- Every third-party dependency must be approved beforehand. These approvals
  can be stored in a dedicated memory, paying attention to any licensing or usage restrictions.
